Connect the Pi

Once, on the Pi. Afterwards it connects by itself at every boot, and the header here says Pi online.

  1. Get the latest code

    cd ~/light-polluter
git pull

  2. Save the broker settings

    Put these lines in ~/.config/light-polluter/rig.env. Every script reads them, so --broker isn't needed any more.

    {{ pi_env.replace(pi_env.split("RIG_MQTT_PASSWORD=")[1].strip(), "••••••••") if has_pi_password else pi_env }}
    {% if has_pi_password %}{% endif %}
    {% if not has_pi_password %}

    MQTT_PI_PASSWORD isn't set on the app, so the password is missing here. It's on the broker service in Railway.

    {% endif %} 
    mkdir -p ~/.config/light-polluter
nano ~/.config/light-polluter/rig.env      # paste, then Ctrl+O, Enter, Ctrl+X
chmod 600 ~/.config/light-polluter/rig.env

  3. Install the agent

    It runs in the background, starts at boot, and starts and stops sessions when you ask here. It also sets up the pollution LED's hardware PWM at boot, so sudo sh setup_pwm.sh isn't needed any more.

    sh pi/install_agent.sh

    Its log: journalctl -u rig-agent -f. After a git pull, restart it with sudo systemctl restart rig-agent; a running session keeps going.

Scripts started by hand

They still work, and their data comes here too: python session.py --plan pollution-check on the Pi, with no --broker. The Live page shows them, and can stop them.
